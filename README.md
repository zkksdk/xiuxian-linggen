# 灵根演化 · 问道长生

一款中国古典修仙风格的 **放置 / 策略构筑** 游戏。

> **核心创新：灵根不是标签，而是会终身演化的活体系统。**
> 你修的火系功法、服下的丹药、嵌进阵眼的法宝、在奇遇里做的每一个选择，都会悄悄改写你的灵根。

纯 HTML / CSS / JavaScript，**无任何外部依赖、无 CDN、无需构建**。
双击 `index.html` 即可运行，也可放在任意静态服务器上。

**🎮 在线试玩** → https://zkksdk.github.io/xiuxian-linggen/
**📦 仓库** → https://github.com/zkksdk/xiuxian-linggen

## 一、玩法速览

### 修行主循环

| 系统 | 说明 |
|---|---|
| 打坐修炼 | 修为自动累积，满即可突破。每踏入新大境界须**择一条道途分支** |
| 境界体系 | 淬体 → 炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫（10 境 × 3 阶 = 30 节点） |
| 天劫 | 金丹起，踏入新大境界降下天劫（三重雷劫 / 五行雷劫 / 心魔劫 / 九天玄劫…），失败则境界跌落、道心受损 |
| 金丹品级 | 凝丹时按灵根纯度、道心、因果、共鸣、功法定品，一品至九品 |
| 飞升 | 渡劫后期可引动九天玄劫，渡过即飞升（额外轮回点） |
| 因果与道心 | 善恶抉择积累因果，影响天劫难度；道心过低会走火入魔 |
| 无情道 / 有情道 | 开局立道：一个偏独修，一个偏宗门 |

### 灵根演化（核心）

| 系统 | 说明 |
|---|---|
| 九灵根 | 金木水火土（五行）+ 风雷光暗（异种），纯度 0–100% |
| 动态演化 | 修炼、丹药、灵阵中的法宝属性、奇遇抉择，都会改写纯度 |
| 数量决定资质 | 单灵根 ×2.4 修炼最快但功法受限；五灵根 ×0.92 缓慢但可通学诸法 |
| 灵根共鸣 | 相生双灵根齐 ≥80% → 触发共鸣 |
| 灵根冲突 | 相克双灵根齐 ≥68% → 互相消磨、削修炼速度，需洗灵丹或奇遇调和 |
| 混沌灵根 | 五条以上纯度俱达 85% → 觉醒，修炼 ×2.6 且可修一切功法 |

### 策略构筑

| 系统 | 说明 |
|---|---|
| 灵阵十二阵眼 | 乾坤兑离震坎巽艮中宫雷枢光台暗渊，各有五行归属。同属 ×1.28 / 相生 ×1.12 / 相克 ×0.78，**相邻阵眼另算阵势** |
| 五行套装 | 阵眼或装备位同属成组：3 件「同气连枝」+3%、6 件「五行归一」+7%、9 件「万法朝宗」+13%。**与阵眼契合形成取舍**——全堆同属拿套装，就吃不到各格契合 |
| 法宝 24 形制 | 剑刀枪弓印符幡旗镜甲袍鼎钟冠簪珠靴履环佩玉灯塔，**形制决定能戴哪一格**，还会带偏词条（剑多攻伐、甲多护体） |
| 法宝 48 品阶 | 黄玄地天灵君王皇尊圣帝仙十二品 × 下中上极 |
| 人物装备 6 格 | 兵器 / 副手 / 护身 / 头冠 / 足履 / 玉佩。**与十二阵眼共用同一批法宝**——嵌阵眼不拘形制，随身佩戴则挑剔形制，二者只能择一 |
| 词条三层 | ①基底词条（17 条）②形制词条（各形制偏好）③**来历词条**（12 条，专属强效） |
| 法宝重铸 | 消耗灵石 + 同属性矿石，保留形制/品阶/来历/烙印，只重掷天生词条 |

### 机缘生成（法宝的来源即其形态）

法宝不是"抽"出来的，而是**按出处长出来的**——五种来源各自构造一份「机缘签名 Sig」，驱动同一个生成器：

| 来源 | 决定因素 |
|---|---|
| **炼器** | 主料定属性、辅料定形制、引材定词条；三件同属→「纯属」、三相生→+1 词条、有相克→「逆炼」（品阶 −1 但必出来历） |
| **妖兽掉落** | 属性同属、按种族定形制（岩魔出甲钟、鬼修出幡灯）、首领必带本命来历 |
| **区域风土** | 青云出佩玉簪、赤炎出剑鼎、紫雷出枪弓钟、遗迹出幡符印……各有特产机制 |
| **秘境** | 每深一层品阶 +0.55、来历率 +6%；秘境之主必掉专属法宝 |
| **奇遇抉择** | 你在事件里的选择写成语义标签，下次生成时被消耗，并额外 +30% 来历概率 |

**来历词条**（血煞 / 太古 / 幽冥 / 雷罚 / 兽魂 / 宗门 / 善缘 / 血债 / 渎神 / 天工 / 玄机 / 太清）部分还带战斗印记：血煞=致命一击回血、雷罚=受击 10% 反伤、太古=参悟碎片 −1。

### 生产与经营

| 系统 | 说明 |
|---|---|
| 炼丹 | 君臣佐使六槽配伍，君药定药性，五行生克决定药力，年份影响品质 |
| 炼器 | 主料/辅料/引材 + 三档火候（文火·武火·文武火） |
| **灵材烙印** | 每种矿石/灵草自带 1~2 条烙印类型；炼器时按 **26% + 火候13% + 阶位×4.5% + 器坊×1.8%**（上限 78%）逐条继承，**不占天生名额**（最多 +2）。材料只存「类型 + 阶位」，**数值在炼成那一刻现算**——同一块料每次出数不同 |
| 阵法 | 八门 × 九宫 × 天干推算，宫干相生 +45%、相克 −35%，可布聚灵/护山/杀阵/迷阵等七种 |
| 宗门经营 | 八大建筑 + 弟子招募与分工，灵田→丹房→弟子→更高级灵田的资源链 |
| **弟子特性** | 10 种（灵田熟手/矿脉慧眼/丹道天才/锻器巧手/阵法奇才/博闻强识/藏经掌书/剑心通明/福缘深厚/好为人师），派驻对口建筑时加成翻倍；招募 35% 概率出双特性 |
| **派遣任务** | 采药 / 探矿 / 猎杀 / 废墟寻宝 / 险地探秘。人越多越快（最多 −45% 用时）、收获越多（最多 +80%）；归来弟子涨经验涨境界 |

### 探索与长线

| 系统 | 说明 |
|---|---|

## 三、数值与节奏（实测）

**难度曲线**——前段轻快，中后段逐层增陡：

```
所需修为 = 200 × 1.58^节点 × 1.062^max(0, 节点-6) × 前期折扣
```

**纯挂机、零操作**的推进速度（无轮回，模拟数据）：

| 时间 | 境界 |
|---|---|
| 27 秒 | 第一次突破 |
| 1.5 分钟 | 炼气 |
| 10 分钟 | 筑基 |
| 25 分钟 | 金丹 |
| 45 分钟 | 元婴 |
| 1 小时 | 化神 |
| 1.5 / 2 小时 | 炼虚 / 合体 |
| 3.5 小时 | 大乘 |
| **10～11 小时** | **渡劫后期（可飞升）** |

主动操作（丹药 / 加速修炼 / 探索 / 功法 / 灵阵）可压到 **4～6 小时**。

**多周目加速曲线**：

| 世 | 通关耗时 | 轮回加持 |
|---|---|---|
| 第 1 世 | 10.6 h | ×1.00 |
| 第 2 世 | 6.1 h | ×1.30 |
| 第 3 世 | 4.1 h | ×1.60 |
| 第 4 世 | 3.4 h | ×1.90 |

**战斗四维走数值制**（不是百分比叠乘）：

```
攻击 = (基础攻 + Σ词条数值 + 灵力×0.55) × (1 + 稀有来源百分比)
```

只有境界分支 / 金丹品级 / 道 / 星盘这类**稀有来源**才用百分比，写在最后。
再加上软上限（`U.soft(x, knee, rate)`：超出 knee 的部分只按 rate 计入），
满配后期从「攻 ×897 / 血 ×1947」收敛到「攻 ×32 / 血 ×22」，战斗从 1~2 回合秒杀变成 10 回合拉锯。

其他数值：

- **在线修为**：基础 1/秒 × 灵根总效 × 1.28^境界节点 × 各项加成
- **离线收益**：在线速率的 **50%**（宗门产出 60%），最多结算 12 小时
- **灵石收入**：(0.8 + 1.28^节点 × 0.5)/秒 × 宗门加成 —— 保证开局不会因缺灵石死锁
- **宗门建筑**上限 12 级；法力/魂力等各类加成均设软上限

> 想自己调快慢：URL 加 `?dev=1`，控制台改 `XX.G.REQ_BASE` / `REQ_ADD` / `REQ_KNEE` / `EARLY`（数值越小越轻松），改完 `XX.G.recalc()` 即见变化。

## 七、存档

- `localStorage` 键名 `xx_linggen_save_v1`
- 每 10 秒自动保存，切后台 / 关闭页面时也会存一次
- 存档带**版本号校验**，版本不符自动弃档重开（不会崩）
- 启动时会跑一次 `G.repairTreasures()`，修复历史数据里的异常词条（数值为 0、超标、缺字段）
- 设置页可导出 / 导入存档文本，或彻底重置

## 八、兼容性说明

游戏**刻意不使用**视口单位（`vh/dvh`）、毛玻璃（`backdrop-filter`）和位移动画（`transform`）。

原因是 App 内置的 WebView 容器（OpenMinis / 微信 / 各类预览器）经常把它们算错：

| 症状 | 元凶 |
|---|---|
| 标签栏跑到屏幕中间、下方整块黑 | `#app{ height:100dvh }` 被算成 0 → flex 高度链断裂 |
| 弹窗只画出标题一条 | `.modal{ max-height:88vh }` 被算成极小值 → 内容被裁 |
| 弹窗内容 / 子节点漏绘 | `backdrop-filter` 提升独立合成层后子节点不绘制 |

**对策**：

- `#app` 用 `position:fixed` + 四边偏移（不依赖高度百分比 / 视口单位）
- 弹窗、提示条、按钮反馈只用 `opacity` 动画
- 面板一律半透明纯色 / 渐变，无 `backdrop-filter`
- 弹窗不用 `max-height`，改为「外层滚动容器 + `margin:auto`」
- 布局不用 `inset`，一律 `top/left/right/bottom`
- 启动 / 尺寸变化时跑 `layoutFix()`：测量 `#app` 高度，异常就定死像素高度兜底
- 弹窗渲染后跑 `UI.repaintFix()`：内容区高度异常则强制重新合成
- **设置 → 诊断**：显示资源版本 / 视口 / 主容器高度，附「强制刷新（清缓存）」按钮

> 若看到旧界面：**设置 → 诊断 → 强制刷新**，或关掉预览重新打开。
