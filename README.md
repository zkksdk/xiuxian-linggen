# 灵根演化 · 问道长生

一款中国古典修仙风格的放置 / 策略构筑游戏。
**核心创新：灵根不是标签，而是会终身演化的活体系统。**

纯 HTML / CSS / JavaScript，无任何外部依赖、无 CDN、无需构建。
直接双击 `index.html` 即可运行（也可放在任意静态服务器上）。

## 兼容性说明（Android WebView 踩过的坑）

游戏里**刻意不用**视口单位（`vh/dvh`）、毛玻璃（`backdrop-filter`）和位移动画（`transform`）。
原因是 App 内置的 WebView 容器（OpenMinis / 微信 / 各类预览器）经常把它们算错，表现为：

| 症状 | 元凶 |
|---|---|
| 标签栏跑到屏幕中间、下方整块黑 | `#app{ height:100dvh }` 被算成 0 → flex 高度链断裂 |
| 弹窗只画出标题一条 | `.modal{ max-height:88vh }` 被算成极小值 → 内容被裁 |
| 弹窗内容/子节点漏绘 | `backdrop-filter` 提升独立合成层后子节点不绘制 |

**对策**：

- `#app` 改为 `position:fixed` + 四边偏移（不依赖高度百分比/视口单位，任何 WebView 都稳）
- 弹窗、提示条、按钮反馈只用 `opacity` 动画，不用 `transform`
- 面板一律半透明纯色/渐变，无 `backdrop-filter`
- 弹窗不用 `max-height`，改为「外层滚动容器 + `margin:auto`」
- 布局不用 `inset`，一律 `top/left/right/bottom`
- 启动时 + 尺寸变化时跑 `layoutFix()`：测量 `#app` 高度，异常就定死像素高度兜底
- 弹窗渲染后跑 `UI.repaintFix()`：内容区高度异常则强制重新合成
- **设置页 → 诊断**：显示当前资源版本 / 视口 / 主容器高度，附「强制刷新（清缓存）」按钮

> 若看到旧界面：**设置 → 诊断 → 强制刷新**，或关掉预览重新打开。

> 底部标签栏为 **两行宫格**（13 个入口一屏看全，无需横向滚动），
> 需要处理的事会亮**红点**，有机会可做的亮**金点**。

## 数值与节奏（实测）

难度公式是一条「前段轻快 + 中后段逐层增陡」的曲线：

```
所需修为 = 200 × 1.58^节点 × 1.062^max(0, 节点-6) × 前期折扣
```

**纯挂机、不做任何操作**的推进速度（无轮回，模拟数据）：

| 时间 | 境界 |
|---|---|
| 27 秒 | 第一次突破（淬体中期） |
| 1.5 分钟 | 炼气 |
| 10 分钟 | 筑基 |
| 25 分钟 | 金丹 |
| 45 分钟 | 元婴 |
| 1 小时 | 化神 |
| 1.5 小时 | 炼虚 |
| 2 小时 | 合体 |
| 3.5 小时 | 大乘 |
| **10～11 小时** | **渡劫后期（可飞升）** |

主动操作（丹药 / 加速修炼 / 探索 / 功法 / 灵阵）可把首周目压到 **4～6 小时**。

**多周目加速曲线**（实测同一套自动打法）：

| 世 | 通关耗时 | 轮回加持 |
|---|---|---|
| 第 1 世 | 10.6 h | ×1.00 |
| 第 2 世 | 6.1 h | ×1.30 |
| 第 3 世 | 4.1 h | ×1.60 |
| 第 4 世 | 3.4 h | ×1.90 |

- **在线修为**：基础 1/秒 × 灵根总效 × 1.28^境界节点 × 功法/灵阵/宗门/阵法/星盘/道途/轮回 加成
- **离线收益**：在线速率的 **50%**（宗门产出 60%），最多结算 12 小时
- **灵石收入**：(0.8 + 1.28^节点 × 0.5)/秒 × 宗门加成 —— 保证开局不会因缺灵石而死锁
- **宗门建筑**上限 12 级（防止加成无限滚）

> 想自己调快慢：URL 加 `?dev=1`，控制台改 `XX.G.REQ_BASE`（基准）/ `REQ_ADD`（后期陡度）/ `REQ_KNEE` / `EARLY`（开局折扣），
> 数值越小越轻松。改完 `XX.G.recalc()` 即可看到 `+X/秒` 变化。

## 交互提示

- 底部标签栏按修行进度**逐步解锁**（约 5 分钟内全部开放）
- 灵阵页点阵眼 → 下方选法宝 → 「嵌入」；也可一键「自动布阵」（按五行推演最优解）
- 丹房点灵草依次填入 君→臣→佐→使；「智能配伍」自动配最优
- 器坊选主料/辅料/引材 + 火候；「智能选材」自动挑
- 战斗页「按住加速」可临时 ×3
- 设置页可导出/导入存档文本，或彻底重置

## 调试

在 URL 后加 `?dev=1` 打开控制台，可用：

```js
__dev.fast(3600)      // 快进 1 小时修炼
__dev.node(20)        // 直接跳到指定境界节点
__dev.all()           // 给一大笔资源、矿石、法宝、碎片
__dev.treasure(20)    // 生成 20 件法宝
__dev.battle(2)       // 打一场 2 倍强度的首领战
__dev.secret()        // 立刻开一次秘境
__dev.points(80)      // 加 80 轮回点
```

## 存档

`localStorage` 键名 `xx_linggen_save_v1`，每 10 秒自动保存，切后台 / 关闭页面时也会存一次。
存档带版本号校验，版本不符会自动弃档重开（不会崩）。
